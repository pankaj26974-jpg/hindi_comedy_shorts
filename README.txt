HINDI COMEDY SHORTS STUDIO — VERSION 4

NEW IN V4
- Mixed Comedy script and scene planner.
- Upload one image per scene (your own images or images made with a free image tool).
- Suggested image prompt for the selected comedy topic.
- Record your own voice using the phone microphone.
- Export vertical 9:16 WebM video; recorded voice is included when browser audio recording/mixing works.

LIMITATIONS
- No built-in AI image generation; upload images yourself.
- Browser TTS is preview only and is not embedded. Use microphone recording for voice in exported video.
- Export is WebM, not MP4. Browser support varies.
- Microphone access may require opening the page in Chrome and granting permission.
- Keep the page open during export.

ANDROID QUICK START
1. Download and extract this ZIP to a NEW folder; keep V3 as backup.
2. Open index.html in Chrome.
3. Generate a script.
4. For each scene, upload an image. You can first try without images.
5. Tap Start Recording, speak the full script, then Stop Recording.
6. Preview the audio, then tap Render & Save Video.
7. Check Downloads for hindi-comedy-short-v4.webm.
